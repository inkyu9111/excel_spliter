# Excel File Toolkit

Excel Table을 **병합·분할**하고, 파일을 **비교**하거나 **시트 정리** 결과를 저장하는 Windows 앱입니다. 데스크톱 Microsoft Excel이 필요하며 `.xlsx`를 지원합니다.

## 실행과 화면

[저장소](https://github.com/inkyu9111/excel_spliter)를 내려받은 폴더에서 `dist/ExcelFileToolkit.exe`를 실행합니다. Python 설치 없이 사용할 수 있습니다. 기본 화면은 **파일 병합**이며 상단에서 분할·비교·시트 정리로 이동합니다.

파일 목록과 저장 위치를 정한 뒤 하단 **시작** 버튼을 누릅니다. 분할·병합은 사전 검사부터 저장까지 자동으로 이어지며 미리보기 단계가 없습니다. 진행 단계와 경과 시간은 설정을 스크롤해도 표시됩니다. 완료 후 결과 파일·폴더를 열거나 병합 결과를 바로 비교대상으로 넘길 수 있습니다. 실행 중에는 입력 변경과 창 닫기를 잠급니다.

**로그 보기**에서 진단을 확인할 수 있습니다. 오류에는 실패한 파일·단계와 다음 조치를 표시하며 상세 내용과 로그를 복사해 전달할 수 있습니다. 시작할 때 현재 입력과 저장 위치를 검사하며 잘못된 파일은 원인과 함께 안내합니다.

## 작업별 사용법

| 작업 | 입력과 순서 | 결과 |
|---|---|---|
| 파일 병합 | 파일 2개 이상 추가 → 목록 순서 조정 → 결과 경로 → 병합 시작 | 목록 순서대로 Table 데이터 행을 합친 파일 |
| 파일 분할 | 원본 → 시트 → 분류 컬럼 → 파일명 패턴·출력 폴더 → 분할 시작 | 분류값마다 선택 시트 하나가 있는 파일 |
| 파일 비교 | 기준·비교대상 → 셀 위치 또는 키 비교 → 새 결과 경로 → 비교 시작 | 차이를 노란색으로 표시한 비교대상 복사본 |
| 시트 정리 | 원본·시트 → 정리할 항목 → 새 결과 경로 → 정리 시작 | 선택한 도형·메모·채우기·조건부 서식을 정리한 복사본 |

### 병합

각 파일에 **워크시트 하나와 정식 Excel Table 하나**가 있어야 합니다. Table은 Excel의 **삽입 → 표**로 만든 표이며, 모든 입력의 열 이름과 순서가 같아야 합니다. 목록의 위·아래 버튼으로 순서를 바꾸고 여러 파일을 함께 제거할 수 있습니다.

- 빈 Table은 0행으로 처리합니다. 중복 행과 숨김·필터로 가려진 행도 포함합니다.
- 첫 파일의 레이아웃·Table 스타일·합계 설정을 사용합니다. 다른 파일의 Table 밖 콘텐츠는 병합하지 않습니다.
- 데이터 값과 셀 서식을 복사하며 **Table 데이터 본문의 수식은 실행 중 Excel에서 다시 계산한 값으로 저장**합니다. 마지막으로 저장된 계산값과 다를 수 있습니다. 첫 파일의 합계 행 수식은 유지합니다. 원본 순서 복원이나 중복 제거 기능은 없습니다.
- 입력값을 묶음 단위로 기록하고, 저장한 결과를 Excel에서 다시 열어 행 수·열 구조·값·자료형·수식 잔존 여부를 검사합니다. 검사 실패 결과는 최종 경로에 게시하지 않습니다.
- 모든 입력의 동일한 단일 전체 열 조건부 서식은 지원 조건을 만족하면 전체 열 범위로 복원합니다. 복잡하거나 서로 다른 규칙은 Excel의 병합 서식을 유지하고 로그에 사유를 남깁니다.

보호되거나 숨겨진 시트, 외부 연결 Table, 1900/1904 날짜 체계가 섞인 파일은 거부합니다. 첫 Table이 확장될 영역에 값·수식·메모·하이퍼링크·병합 셀이 있거나 Excel 행 한도를 초과해도 실행하지 않습니다. 빈 셀의 서식은 허용합니다.

### 분할

선택한 시트는 표시 상태여야 하며 데이터 행이 있는 Table이 정확히 하나 있어야 합니다. 분류 컬럼의 값과 자료형을 기준으로 묶으며 빈 셀도 하나의 분류입니다. 원본의 다른 시트는 결과에서 제거됩니다.

파일명 패턴의 `%`는 각 분류에서 처음 나타난 셀의 표시 문자열로 바뀝니다. 예: `%_분할` → `서울_분할.xlsx`, 빈 값 → `_분할.xlsx`. 숫자 `1`을 `000` 서식으로 표시한 첫 셀은 `001_분할.xlsx`가 됩니다. 같은 값의 표시 서식이 달라도 첫 셀을 기준으로 이름을 정합니다. `.xlsx`는 자동으로 붙이고 금지 문자·예약 이름과 이름 충돌은 안전한 파일명으로 바꿉니다. 시작 시 결과 파일명을 계산하고 기존 파일과 겹치면 덮어쓰기를 확인합니다.

필터는 작업 사본에서 해제해 전체 행을 분류합니다. 선택 시트의 메모·댓글·그림·차트·버튼 등 모든 도형은 결과에서 삭제하며 실행 전에 안내합니다. 다른 시트를 참조하는 수식 등은 시트 삭제로 `#REF!`가 될 수 있습니다. Table 아래 독립 콘텐츠나 보호·외부 연결 Table은 지원하지 않습니다.

일부 분류만 실패하면 이미 완료된 파일은 유지하고 성공·실패·미처리 목록을 구분합니다.

### 비교와 시트 정리

**셀 위치 비교**는 같은 이름의 시트에서 같은 좌표를 비교합니다. **키 비교**는 양쪽 Table과 공통 키 컬럼을 선택하고, 키가 같은 행을 열 이름으로 비교합니다. 키 조합은 각 Table에서 유일해야 합니다. 행·열 순서가 바뀐 분할/병합 결과에는 키 비교가 적합합니다.

문자열의 공백·대소문자와 숫자·문자·논리값을 구분합니다. 빈 셀과 빈 문자열은 같은 빈 값으로 취급합니다. 양쪽 파일을 Excel에서 각각 다시 계산한 값을 비교하되 결과에는 비교대상의 수식을 유지합니다. 외부 링크는 갱신하지 않습니다. 변경·추가·누락 건수는 전체 데이터 기준이며 화면 상세는 최대 1,000건입니다. 기준에만 있는 시트·행은 내역으로 안내하고 결과에 새로 만들지 않습니다.

키 비교는 값이 바뀐 셀 수와 추가·누락 행 수를 구분합니다. 추가 행은 전체 행을 노란색으로 표시하므로 표시된 셀 수가 값 변경 셀 수와 다를 수 있습니다. 위치 비교는 양쪽 사용 영역에서 비어 있지 않은 셀의 좌표를 합쳐 비교합니다. 비교대상에만 있는 시트·영역의 값은 추가로 표시하며, 기준에만 있는 시트는 누락 시트로 안내합니다. 위치 비교의 차이는 셀 수이며 행 추가·삭제 건수를 뜻하지 않습니다.

시트 정리는 선택한 시트에만 적용합니다. **셀 채우기색 초기화**는 직접 지정한 색을 지우며 기본적으로 Table 헤더는 제외합니다. Table 스타일은 유지합니다. **조건부 서식 삭제**는 별도 옵션이고 헤더 제외와 무관하게 선택 시트의 규칙을 모두 삭제합니다.

## 원본과 결과 보호

원본은 읽기 전용으로 열거나 사본에서 처리하며 저장하지 않습니다. 입력 경로로 출력하는 요청, 사전 검사 이후 바뀐 입력·출력은 거부합니다. 분할·병합은 승인한 기존 결과만 교체하며, 비교·정리는 항상 새 파일명을 사용합니다. 결과 파일은 임시 저장과 검증을 마친 뒤 확정합니다.

DRM 파일은 사용자의 Excel 읽기·저장 권한으로 처리합니다. 일반 `.xlsx` 사본을 만들 수 없는 정책이면 실패합니다. DRM 유지나 우회는 제공하지 않으며 실제 회사 DRM 환경은 별도 검증이 필요합니다.

병합은 셀 서식을 보존하기 위해 Windows 클립보드를 사용합니다. 작업 중 다른 프로그램에서 복사·붙여넣기를 하면 실패할 수 있습니다. 값 손상은 게시 전 검사로 차단하지만 모든 서식의 동일성을 자동 증명하지는 않습니다.

강제 종료 시 출력 폴더에 `.e*` 작업 폴더나 `.em-*`, `.ec-*`, `.et-*` 임시 파일이 남을 수 있습니다. 앱이 종료되고 해당 파일을 사용하는 Excel이 없는지 확인한 뒤 해당 작업의 임시 파일만 정리하세요. `.esr-*`는 기존 결과의 복구 파일이므로 내용 확인 전 삭제하지 마세요.

로그: `%LOCALAPPDATA%\ExcelFileToolkit\logs\excel-file-toolkit.log`. 파일 경로·단계·기술 예외를 기록하며 비교 셀 값은 기록하지 않습니다.

## 개발과 검증

Windows 10/11, Python 3.12 64비트, 데스크톱 Excel 2016 이상을 사용합니다. 아래 명령은 저장소 루트 폴더에서 실행합니다.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m excel_splitter
```

일상 회귀 검사는 데이터 손실 방지·오류 복구·실제 Tk 흐름을 확인합니다. 실제 Excel 검사는 별도 선택하며 모든 검사를 하나씩 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m pytest -q -rs
$env:EXCEL_E2E = "1"
.\.venv\Scripts\python.exe -m pytest tests/e2e -q -s
Remove-Item Env:EXCEL_E2E
```

E2E는 합성 자료로 분할→병합, 값·서식·오류 셀·빈 표·필터·날짜 체계·파일 잠금·오류 후 재실행·원본 보존, 비교, 정리를 검사합니다. 실제 Excel 없이 건너뛴 검사는 통과로 세지 않습니다. Windows 권한이 없어 심볼릭 링크 테스트가 skip되면 그 범위도 미검증입니다.

빌드:

```powershell
.\scripts\build.ps1
```

기본 인터프리터는 `.venv\Scripts\python.exe`입니다. `-PythonExe`로 변경할 수 있습니다. 동일 소스의 회귀 검사를 이미 마쳤다면 `-SkipTests`로 중복 실행을 생략할 수 있습니다. 빌드는 고정 의존성, 단일 EXE의 pywin32 로딩, 실제 창 시작·종료를 확인합니다. 결과는 `dist\ExcelFileToolkit.exe`입니다.

설계와 보존 계약은 [설계 문서](docs/DESIGN.md), 실제 실행 결과와 측정 한계는 [검증 기록](docs/VALIDATION.md)을 참고하세요.
