# 승인된 Toolkit 화면 적용

사용자가 승인한 비교 설정·결과·시트 정리 시안을 기존 Tk/ttk 프로그램에 적용한다.

- work_unit: 네 탭의 UI와 비교 상세·작업 진행·저장 경로·오류 안내
- model/effort: gpt-5.6-sol / high (GUI·비교), gpt-5.6-terra / high (서비스 진행), inline/current (공통 안내)

- proof: 변경 동작의 단위 테스트, 실제 Tk 위젯을 통한 화면 흐름 확인, `scripts/build.ps1`
- review: `git diff 4dbfe28b45e2d49833ee615d13fbac128fffa3e1`; 원본/기존 결과 보존, 비교 내역 정확성, 실행 중 상태 일관성

## 구현 범위

1. 네 탭에 파일 → 작업 설정 → 저장 위치 순서를 적용하고 시트 정리 옵션 관계를 유지한다.
2. 위치/키 비교를 라디오 선택으로 표시하고 필요한 설정만 보여준다.
3. 변경·추가·누락 요약과 위치·키·값이 있는 비교 내역을 화면에 남긴다. 큰 결과는 표시 한도와 전체 건수를 명시한다.
4. 완료 후 파일·폴더 열기 및 병합 결과를 비교대상으로 전달하는 동작을 제공한다.
5. 실제 작업 단계와 경과 시간을 보여준다. 완료량을 모르는 단계는 백분율을 추측하지 않는다.
6. 경로 문제를 입력 중 안내하고 사용 가능한 새 파일명을 추천한다. 분할의 폴더 생성 질문과 기존 덮어쓰기 확인을 유지한다.
7. 오류는 쉬운 설명과 조치부터 표시하고, 원문·로그 정보는 상세 보기와 복사로 제공한다.

새 UI 의존성은 추가하지 않는다. Excel이 없는 개발 환경에서는 COM 테스트 더블과 패키징/화면 검증까지 가능하며, 실제 Excel 파일 처리는 별도 실행 환경이 필요하다.

## 구현 검증

- 단위 테스트 349개 통과. 기존 테스트용 진행 표시 객체도 실제 Tk API에 맞춰 갱신했다.
- 실제 Tk 화면에서 네 탭, 1024×800/760×560 크기, 키 설정, 진행 상태, 결과 열기, 병합 결과 전달, 정리 옵션 의존성, 오류 상세를 확인했다.
- 시작 버전 대비 변경분 검토와 마지막 오류 처리 분기 검토에서 차단 문제가 없었다.
- 결과 상세는 최대 1,000건이며 긴 값은 선택 내역 상세 창에서 읽는다. 전체 건수와 색칠은 제한하지 않는다.
- `scripts/build.ps1` 통과: 단일 EXE·폴더형 빌드, 시작 검사, 단일 EXE의 pywin32 로딩 검사 완료.
